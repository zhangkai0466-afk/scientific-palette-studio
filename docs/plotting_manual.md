# Science Palette Studio 绘图手册

## 硬性规则 PS-FILL-001：纯色图形禁止黑色描边

本规则是渲染器级约束，所有现有图型和未来新增图型必须遵守。

### 适用对象

- 柱形、面积、小提琴、直方图等填充区域
- 散点、气泡、网络节点等实心标记
- 饼形、径向柱形、堆叠区域等相邻色块
- 图例和界面中用于表示数据的纯色色块

### 强制实现

```python
FILL_EDGE = "none"

ax.bar(..., edgecolor=FILL_EDGE, linewidth=0)
ax.scatter(..., edgecolors=FILL_EDGE)
ax.fill_between(..., edgecolor=FILL_EDGE, linewidth=0)
```

### 允许的结构线

- 坐标轴、刻度、误差线、置信区间中心线和参考线
- 箱线图中表达中位数和四分位数的中性灰结构线
- 为了分隔相邻色块使用的白色间隔线

上述线条必须有数据或结构语义，不得变成纯色图形的黑色外轮廓。

## 颜色不足时的区分顺序

1. 直接标签或形状标记
2. 留白或白色间隔
3. 透明度、明度层级或线型
4. 分面和小倍图

黑色描边不在可选项中。

## 色库类型

- `categorical`：用于无序类别，颜色可以按类别需要选取，但同一图内映射必须保持稳定。
- `continuous`：用于连续数值或双向偏差，色卡顺序具有语义，任何子集都必须保持原始先后顺序。
- 连续色库用于热图、空间场和数值映射时应调用 `LinearSegmentedColormap`；离散类别优先调用 `ListedColormap`。
- 不得为了增加类别区分而打乱渐变色库的端点、中点和方向。

## 预览字号

- 工作台预览基础字号：9.2 pt
- 坐标轴标题：9.4 pt
- 刻度：8.4 pt
- 图例：8.0 pt
- 正式投稿时仍应按目标期刊最终版面尺寸重新核验

## 图形输出

- Python/Matplotlib 是唯一图形渲染后端
- SVG 保留可编辑文字，`svg.fonttype = "none"`
- PDF 使用 TrueType 42，`pdf.fonttype = 42`
- PNG 用于工作台预览和快速导出
